# Spotify Clone

A static Spotify-inspired website created using **HTML** and **CSS**.

## About the Project

This project is a recreation of the Spotify web interface, created for practice and to improve my frontend development skills.

The website focuses on the layout and visual design of Spotify using only HTML and CSS.

## Technologies Used

* HTML5
* CSS3

## Features

* Spotify-inspired dark interface
* Navigation sidebar
* Search bar
* Recently played section
* Album and playlist cards
* Responsive design

## Project Status

**In progress**

## Purpose

This project was created to practice:

* HTML
* CSS
* Flexbox
* Responsive web design
* Creating layouts from existing designs
